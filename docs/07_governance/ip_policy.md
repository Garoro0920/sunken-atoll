# 知的財産方針

## 1. 目的

本プロジェクトが扱う **知的財産(IP)** の権利関係・帰属・利用範囲を定義し、内部運用と対外公開のルールを統一する。

## 2. 自社 IP

- プロジェクトの中核 IP(ゲームタイトル、世界観、主要キャラ、固有名詞、ロゴ)はプロジェクトオーナーに帰属
- 寄稿者(コントリビュータ)契約は採用方針に応じ別途
- ファンアート / ファンメイドコンテンツの取扱方針を `community.md`(任意)に定める

## 3. 第三者 IP

- 既製アセット(Poly Haven, Sketchfab, 購入素材)は利用条件を `pipeline/metadata/` に記録
- 既存作品・キャラクター・実在人物を想起させる表現を避ける
- 引用・パロディ・フェアユースは個別判断、PO 承認

## 4. AI 生成物の権利

- 各サービスの利用規約に従う(`07_governance/licensing.md` 参照)
- 出力物の **権利譲渡 / 排他性 / 商用許諾** を明記
- 規約上の保証範囲(訴訟リスク移転など)を確認

## 5. 名誉・プライバシー

- 実在人物の似顔・声・名前を許諾なく使わない
- ボイスクローンは元提供者の明示同意必須
- 撮影・録音素材は出演者・撮影者の権利を確認

## 6. 商標

- ゲームタイトル、サブタイトル、シンボルロゴは商標調査
- 主要市場(US / EU / JP / 中国 / 韓国 等)で衝突確認
- 必要なら登録(時期・地域は事業判断)

## 7. ドメイン・SNS ハンドル

- ゲーム名と一致するドメイン・SNS を確保
- Cyber/Brand スクワット対策

## 8. オープンソース貢献

- 自プロジェクトから OSS への貢献(パッチ、ライブラリ提供)は OSS 側ライセンスに従う
- 業務時間中の貢献は雇用契約・NDA を確認

## 9. ユーザ生成コンテンツ(UGC)

- ユーザが作成したコンテンツの権利
- プラットフォーム規約(Steam Workshop 等)
- モデレーション方針(暴力・性的・差別)

## 10. アセット流出対応

- リーク発見時は即時連絡窓口へ通知
- 法的措置の選択肢を整理
- 公開後の権利保全は限界があるため、未公開素材の管理を厳格化

## 11. 守秘義務

- 未発表の仕様・アセット・契約情報は機密
- 対外発信は PO 承認
- 退職・離脱時の取扱いを契約に含める

## 12. 海外展開

- 各国の知財法・商標法・著作権法に対応
- 翻訳・現地化時の権利継承
- 第三者代理店利用時の契約

## 13. リスク登録

- IP リスクは台帳化し、四半期で見直す
- 高リスク(模倣・係争)案件はエスカレーション
