# AI 倫理ガイドライン

## 1. 目的

本パイプラインが AI(生成系・LLM・Vision)を多用する性質上、**倫理的に許容される範囲** を明文化し、Claude Code とオペレータの双方が遵守する。

## 2. 基本原則

1. **人間の尊厳・安全を損なわない**
2. **公平・無偏見**(差別を助長しない)
3. **透明性**(AI 利用を隠さない)
4. **説明責任**(誰がどの判断をしたかを追跡)
5. **プライバシー尊重**
6. **法令遵守**

## 3. AI 利用の表示

- AI 生成物を含む作品にはクレジットへ明記
- 主要な生成系サービス名を `localization/credits.md` に記載
- ユーザに対する誤解(「全て手描き」等)を生まない

## 4. 学習データの倫理

- 採用するサービスの学習データの出典を確認
- 著作権侵害の懸念があるサービスを商用採用しない
- 出典表示が必要なサービスは表示する

## 5. 表現規範

### 5.1 禁止
- 実在人物・組織への誹謗中傷
- 違法薬物・武器・テロ等の助長
- 児童に対する性的・搾取的表現
- 民族・性別・宗教・性的指向に対する差別表現
- 自殺・自傷を促す表現

### 5.2 慎重対応
- 暴力・性的表現は対象年齢に応じ抑制(年齢分類: PEGI / ESRB / CERO 等)
- 政治・宗教は文化背景に配慮
- 歴史的悲劇は当事者・遺族へ配慮

## 6. NPC ランタイム LLM の安全

- システムプロンプトで世界観・口調・禁止事項を厳格化
- 出力内容のフィルタ(暴力・性的・差別語)
- ジェイルブレイク試行に対するレスポンス方針
- 実プレイヤーの個人情報を覚えさせない
- 子供向け配信時の追加ガード

## 7. ボイスクローンの倫理

- 同意の得られた話者のみ
- 死者の声、未成年の声、政治家・芸能人の模倣を回避
- 商用利用の同意書を保管

## 8. プライバシー

- 解析・SDK は最小限の情報のみ送信
- 個人特定可能情報は擬似化・匿名化
- 各国法令(GDPR / CPRA / APPI など)を順守
- 同意 UI を必要地域に提供

## 9. 子供への配慮

- 子供向け配信時は COPPA / 各国子供保護法に対応
- 広告・課金を制限
- ペアレンタルコントロール

## 10. ハラスメント・モデレーション

- マルチプレイチャットはモデレーション必須
- 通報・ブロック機能の実装
- 重大違反は永久 BAN

## 11. 透明性レポート

- 大規模配信時は透明性レポートを公開検討(モデレーション統計、AI 利用範囲)
- 変更履歴を可視化

## 12. ステークホルダー対応

- 苦情・要望に対する公式窓口
- 法的請求(削除要請、開示請求)への対応窓口

## 13. リスクアセスメント

- 新機能・新コンテンツ追加時に倫理 / プライバシー / 法令の影響を評価
- 高リスク機能はリリース前に PO + 法務(必要なら専門家)レビュー

## 14. 教育・研修

- チームと Claude Code 双方が本ガイドラインを定期参照
- 重大事案発生時は事例共有

## 15. 例外

- 例外承認は PO 単独で行わない(必要なら専門家を交える)
- 例外は期限付き、`pipeline/exceptions/` に記録

## 16. 反差別・包摂

- キャラ表現の多様性を尊重
- 人種・性別・身体・障害・年齢の表現を慎重に
- ステレオタイプ強化を避ける
