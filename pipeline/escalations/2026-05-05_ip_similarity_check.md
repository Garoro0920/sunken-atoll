`escalation_policy.md` §2.1「**法務・倫理** に関わる判断(著作権、未成年向け表現、暴力表現の線引き)」に該当。即時判断ではないが、対象工程に到達する前に必ず PO 判断を得る必要がある。

## 状況

本作(Project Sunken Atoll(仮))は SUNKENLAND(Vector3 Studio)を**ジャンル方向性の参照点**として開発する。
GDD(`specs/game_design_document.md`)§10 で次を厳守事項として明文化済み:

- タイトル・ロゴ・キャラクタ・固有名詞・固有資産・コード・テクスチャ等は一切流用しない
- マーケティング・ストア記述で「SUNKENLAND の」「SUNKENLAND ライク」等の表記は使用しない
- AI 生成プロンプトに既存タイトル名を含めない

しかし、**実際にビジュアル・命名・ロゴが具体化される段階**で、意図せず類似性が高まる可能性がある(特に AI 生成アセット)。本テンプレ規約 `docs/07_governance/ip_policy.md` §3 / §6 / `docs/07_governance/ai_ethics.md` §4 に従い、**主要意匠の類似性チェックを工程として組込む**必要がある。

## 選択肢

- **A: アート確定の都度、PO + 必要に応じ法務助言で類似性チェック**
  - 利点: 段階ごとに是正が早い、コスト分散
  - 欠点: 工程ごとに判断負荷、判断基準のブレ

- **B: 主要マイルストーン(コンセプトアート確定 / 主要キャラ確定 / ロゴ確定 / ストア提出前)で集中チェック**
  - 利点: 集中判断で基準が安定、チェックのコストを意識的に管理
  - 欠点: 終盤発見時の手戻りが大きい

- **C: 第三者(法務 / 知財コンサル)に最終チェックを委託**
  - 利点: 専門性・客観性、契約上の責任移転
  - 欠点: コスト発生、リードタイム

## 推奨

**A + B の組合せ + リリース前のみ C を選択肢として保留**。

具体運用:
1. **コンセプトアート段階**(GDD §9 Q-09 確定時): PO + CD で「明らかな類似」をスクリーニング
2. **主要キャラ・ロゴ確定前**(マイルストーン): 商標 / 著作権類似性の精査(主要市場 US / EU / JP)
3. **ストア提出前**(リリース前 G3 段階): 全アセットの最終レビュー
4. 本作の事業規模・販売地域が拡大する場合 **C(法務助言)を発動**

## 期限と発動条件

| トリガ | 期限 | 必要な決裁 |
|---|---|---|
| コンセプトアート初稿提出 | 提出から 3 営業日以内 | CD + PO スクリーニング |

| AI 生成プロンプトに既存固有名混入を発見 | **即時** | Claude Code が即時停止し、人間判断を仰ぐ |

## チェック観点(運用テンプレ)

1. **タイトル / ロゴ**
   - 商標調査(US / EU / JP / 中国 / 韓国 — 主要市場)
   - フォント・色・形状の独自性
2. **主要キャラ**
   - シルエット類似性
   - 衣装・装備の特徴的要素
   - 名称
3. **アセット**
   - メッシュ・テクスチャの偶発的一致(AI 生成時の学習データ起因)
   - メタデータの `prompt` / `service` を確認
4. **物語・固有名詞**
   - 場所名・組織名・登場人物名
   - 設定文書の表現
