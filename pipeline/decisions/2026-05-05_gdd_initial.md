# 2026-05-05 GDD 初版採用と本作の方向性確定

## 文脈

本テンプレート(Godot 4 × Claude Code パイプライン)を最初に適用するプロジェクトの **企画方向性が未確定** だった。CLAUDE.md §9「補助情報」が定める初期化要件のうち #3「project_charter.md のスコープと成功基準を該当プロジェクト向けに調整する」が未消化であり、本格作業に着手できない状態にあった。

PO より「水没後の世界を主題とした協力型マルチプレイサバイバルゲーム」を方針として提示。SUNKENLAND(Vector3 Studio)を着想元とする旨も合意。

## 選択肢

- **A: SUNKENLAND を直接的にクローン / 強い類似で開発**
  - 利点: 設計参照が容易、ジャンル既存ファンの取り込みが期待
  - 欠点: 商標・著作権類似のクレームリスク高、ストア審査リスク、ブランド独自性ゼロ、`07_governance/ip_policy.md` §3 と衝突

- **B: SUNKENLAND をジャンル参照点に留め、独自意匠で再構築**
  - 利点: IP リスク低、独自ブランディング可、メカニクスは業界共通のため再構築可能
  - 欠点: ビジュアル・名称・ロゴをすべて独自設計する必要、初期開発コスト増

- **C: 全く別ジャンルへ転換**
  - 利点: 参照点の制約から完全自由
  - 欠点: PO 提示方針(海洋サバイバル)を反映できない、合意済み方針からの逸脱

## 決定

**B を採用**。

GDD(`specs/game_design_document.md`)を初版として作成。同 §10「ライセンス・IP 上の留意事項」で以下を厳守事項として明文化:
- タイトル・ロゴ・キャラクタ・固有名詞・固有資産・コード・テクスチャ等は一切流用しない
- マーケティング・ストア記述で「SUNKENLAND の」「SUNKENLAND ライク」等の表記を使用しない
- AI 生成プロンプトに既存タイトルの直接名指しを含めない
- 主要意匠は商標・著作権類似性チェックを PO 承認前に実施

ジャンル(海洋サバイバルクラフト)・メカニクス一般構造・水没文明モチーフは業界共通の表現空間として、独自意匠で再構築する範囲で許容。

仮タイトル: **Project Sunken Atoll(仮)**(正式タイトルは GDD §9 Q-01 で確定予定)。

## 結果

期待される効果:
- IP リスクを設計段階で抑制
- 動的潮汐 / LLM NPC / 動的派閥関係などの差別化要素により独自プロダクト価値を確保
- PO 提示方針(海洋サバイバル)に整合

引き換えのリスク:
- ビジュアル・命名・ロゴを完全に独自設計する必要があり、コンセプトアート工程でのコスト増
- 「参照しているが類似ではない」境界の判断が継続的に必要 → 主要意匠は PO 承認 + 必要に応じ法務助言
