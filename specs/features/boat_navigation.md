## 1. 目的

筏 / 帆船 / 動力船による航海を実装し、**複数人同乗・操作分担** を主要要素とする(GDD §4.6 協力要素表)。

## 2. ユーザストーリー

- プレイヤーとして、序盤は筏で近距離島間を移動できる。
- 4 人で帆船に乗り、操舵 / 見張り / 砲撃を分担して中距離航海ができる。
- 風向きと自船の進行方向で帆走効率が変わる戦略性がある。
- 嵐時は航海が危険になり、帰港判断が迫られる。

## 3. 要件

### 3.1 船種(MVP)

| 船種 | 解放 | 乗員 | 速度 | 動力 | 用途 |
|---|---|---|---|---|---|
| 簡易筏 | 初期クラフト | 1〜2 | 低 | 手漕ぎ | 近距離 |
| 帆船 | 中盤(T2 拠点) | 2〜4 | 中 | 帆 + 風 | 中距離・複数人 |
| 動力船 | 中〜終盤(T2 + 燃料) | 2〜4 | 高 | 燃料エンジン | 高速・長距離 |
| 潜水艇 | ストレッチ | 1〜2 | 低(水中) | 電力 | 深海帯 |

### 3.2 操船役割(マルチプレイ)

| 役割 | 操作内容 | 担当ノード |
|---|---|---|
| 操舵手 | 進行方向、舵 | 操舵席 Interactable |
| 帆手(帆船) | 帆の角度、上げ下げ | 帆ロープ Interactable |
| 機関手(動力船) | エンジン出力、燃料補給 | エンジン席 Interactable |
| 見張り | 望遠鏡、警告共有 | 望遠鏡 Interactable |
| 砲手(後期) | 砲台操作 | 砲台 Interactable |

各役割は同時に 1 人占有(席ロック)。空席の役割はオフラインまたは AI 補助(MVP は補助なし、空席=機能停止)。

### 3.3 航海物理

- 浮体物理を `building_system.md` の Jolt 浮体モデルと共有
- 推進: 帆(風 × 帆角度)/ エンジン(燃料 + スロットル)/ 手漕ぎ(スタミナ)
- 抵抗: 速度の二乗に比例
- 旋回: 舵角と速度に依存(高速時は急旋回不可)

### 3.4 風と帆船

- 風向 / 風速は `day_night_cycle.md` の天候系から取得
- 帆船の進行効率 = `cos(船首方向 - 風向) × 帆有効性`
- 逆風航行は不可(タッキング: ストレッチ)
- 嵐時の風速で帆破損の判定

### 3.5 嵐イベント連動

- `day_night_cycle.md` の嵐イベント発生時、船は揺れと進路逸脱
- 風速閾値超過で帆を畳まないと破損
- 雷の落雷判定(高所マスト)

### 3.6 マルチプレイ整合

- 船自体はホスト権威の物理オブジェクト
- 操作入力は各クライアントから送信、ホストで適用
- 同乗中のプレイヤー位置は船ローカル座標で同期(`multiplayer_session.md`)
- 船-プレイヤー親子関係の管理に注意(reparent 同期)

### 3.7 燃料・耐久

- 動力船: 燃料消費(時間)、補給は拠点 or 浮遊燃料樽
- 全船種: 衝突 / 嵐で耐久消耗、修理可
- 沈没: 耐久 0 で物理発散 → 一定時間後に消滅、内容物は浮遊

### 3.8 非機能要件

- 1 マップに同時在船 8 隻まで(MVP)
- 物理 tick あたり 16.6 ms 以内
- 船-プレイヤー reparent: 100 ms 以内に全クライアント反映
- 同乗時の同期遅延: 200 ms 以内

### 3.9 テスト観点

- 単体: 風 × 帆角度 → 推進力計算
- 統合: 操舵入力 → 進路変更
- シナリオ:
  - 4 人乗船で操舵 / 帆 / 見張り役割分担
  - 嵐イベント中に帆を畳んで生還
  - 衝突 → 耐久減少 → 修理
  - 沈没 → 浮遊物回収
- マルチプレイ: 同乗・離脱・船切替の同期

## 4. 非要件 / スコープ外

- リアル風シミュレーション(MVP は方向 + 速度のみ)
- タッキング(逆風航行)はストレッチ
- 船同士の衝突詳細物理(MVP は単純判定)
- 内装(船室)の歩行(MVP は甲板のみ)
- AI 操船(全役割空席時の自動操船)
