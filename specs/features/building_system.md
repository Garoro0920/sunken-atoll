# Spec: 建築・浮体拠点システム

| 項目 | 内容 |
|---|---|
| 状態 | Draft |
| 親 GDD | `specs/game_design_document.md` §4.4 / §5.3 |
| 起票日 | 2026-05-05 |
| 関連規約 | `docs/04_standards/scene_standards.md`、`docs/04_standards/asset_standards.md` |

## 1. 目的

水上・浅瀬・島嶼に **浮体ベースの拠点** を構築できるシステムを提供する。マルチプレイで複数人同時建築、共有設計図、構造的整合性(支持・倒壊)を担保する。

## 2. ユーザストーリー

- プレイヤーとして、海上に浮体プラットフォームを置き、その上に居住・機能設備を建てたい。
- 建築家ロールとして、設計効率と素材消費低減の利点を体感したい。
- 仲間と分業して、1 人では運べない大型建材を協力して設置したい。

## 3. 要件

### 3.1 構造階層

```
基礎(Foundation: 浮体 / 杭)
└─ フレーム(Frame: 床・梁)
    └─ 壁・屋根(Wall / Roof)
        └─ 装飾・機能設備(Decoration / Function)
```

各階層は **下位階層に依存** し、依存元が壊れると上位は不安定化 or 倒壊。

### 3.2 浮体物理

- 採用候補物理: Jolt(GDD §7.5)
- 浮体は質量・浮力中心・抗力でシミュレート
- 隣接浮体は接続(剛体ジョイント)で 1 つの構造として扱う
- 大型構造ほど安定、しかし素材コスト高
- 嵐時は不安定化(波高 / 風で揺動)

### 3.3 構造的整合性

- 各部材に「支持必要」「自立可」属性
- 支持を失った部材は崩壊フラグ → 一定時間後に倒壊(救済猶予)
- 倒壊シミュレーションは簡略化(物理破片飛散はパーティクル + 簡易剛体)

### 3.4 ゲームプレイ要素

| 機能 | MVP | ストレッチ |
|---|---|---|
| 配置(スナップ) | ✓ | フリー回転(45 度刻み → 任意) |
| 配置(フリー) | ✓ | 段階的解放(設計ツール装備) |
| 解体・回収 | ✓(部分的素材回収) | 完全回収 |
| 設計図保存 | — | プリセット保存・読込 |
| 共同建築 | ✓(複数人同時配置可) | 大型建材の協同運搬 |
| 建築許可エリア | ✓(派閥領域・他プレイヤー拠点) | 細分化 |

### 3.5 設備カテゴリ(MVP)

- 居住: 寝床、収納、調理、淡水化
- 生産: 作業台、炉、簡易工房
- 防衛: 壁、扉、見張り台、簡易タレット(T2)
- 動力: 風力 / 太陽光発電(T2)、蓄電池
- 移動: 船坞(船建造の起点)

### 3.6 マルチプレイ同期

- 建築物は権威側で永続化(`multiplayer_session.md` §3.3 のワールド状態同期に従う)
- 配置イベントは権威側で衝突 / 許可判定
- 配置プレビューはクライアント側

### 3.7 非機能要件

- 1 拠点あたり構造物 500 個まで安定動作(MVP)
- 描画: LOD0/1/2 必須、遠景は impostor
- 物理: 静的化(動かない部材は static body へ昇格)で性能確保
- セーブ: 1 拠点 < 100 KB の軽量シリアライズ

### 3.8 テスト観点

- 単体: 浮力計算、支持判定
- 統合: 浮体接続 → 大型構造の波揺れ安定性
- シナリオ: 「4 人で T2 拠点を 1 セッションで建造」「嵐イベントで不適切構造が崩壊し適切構造は維持」
- 視覚: 主要設備の配置スクショ baseline
- パフォーマンス: 拠点規模別 FPS / 物理コスト

## 4. 非要件 / スコープ外

- 構造物への雨水浸入 / 内装シミュレーション
- 季節変化に伴う劣化(別 spec: decay_durability)
- 完全自由回転(MVP は 45 度刻み)
- 派閥拠点の AI 行動(別 spec)

## 5. 受入基準(DoD)

- [ ] T1 拠点(浮体 + 寝床 + 倉庫 + 調理 + 淡水化)を 1 人で建造可能
- [ ] T2 拠点(+ 発電 + 農園 + 防壁)を 4 人協力で建造可能
- [ ] 浮体物理が嵐イベントで安定(設計が適切なら倒壊せず)
- [ ] 倒壊シミュレーションが視覚・物理ともに動作
- [ ] マルチプレイ同期テスト緑
- [ ] パフォーマンス予算内(500 構造物時 60 FPS @1080p)

## 6. 想定実装

- 配置: `src/gameplay/building/`、`scenes/prototypes/building_test.tscn`、`resources/data/building/`

## 7. リスクと未決事項

| リスク | 対策 |
|---|---|
| 浮体物理の不安定(振動・破裂) | Jolt 設定の調整 + 部分静的化 |
| 大規模拠点での FPS 低下 | LOD + impostor + 静的バッチング |
| 同期粒度の判断 | プロト計測後に決定し別 ADR 化 |
| 共同建築の権利競合 | 配置ロック(短時間)で衝突回避 |
